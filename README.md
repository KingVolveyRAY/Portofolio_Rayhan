# Website Portofolio Muhammad Rayhan Ramadhan

> **IoT Developer yang membangun sistem dari sensor sampai dashboard**  
> *Bilingual (Indonesian & English) Portfolio with Modern Glassmorphism Design*

Website portofolio dwibahasa untuk **Muhammad Rayhan Ramadhan**, mahasiswa Teknik Informatika UIN Syarif Hidayatullah Jakarta, praktisi IoT, mentor robotika di Scitech Academy, dan pengembang sistem terdistribusi.

---

## Fitur Utama

- **Dwibahasa Penuh (ID & EN)**: Rute independen `/id` dan `/en` untuk setiap halaman dengan pengalih bahasa dinamis di navigasi.
- **Modern Glassmorphism Design**: Palet warna obsidian slate, aksen terracotta (oranye hangat), dan IoT cyan dengan efek kaca backdrop blur halus serta fallback solid.
- **Dukungan Mode Gelap & Terang**: Mode gelap sebagai tampilan utama dengan toggle tema teruji kontras WCAG AA.
- **Katalog 8 Proyek & Studi Kasus**:
  - Tiga proyek IoT unggulan di beranda (*Dashboard Kualitas Air Cuci Sayur*, *WOODGUARD*, *RiverGuard*).
  - Filter kategori dinamis (IoT & Web, IoT, Web App, Backend) dan pencarian teknologi secara real-time.
  - Halaman studi kasus komprehensif mengikuti template PRD (Konteks, Peran, Solusi, Arsitektur, Alasan Teknis, Tantangan, dan Hasil).
- **Layanan Freelance & Alur Kerja**: Tiga penawaran layanan terarah, alur kerja bertahap 4 langkah, dan penanda terbuka untuk peluang magang.
- **Halaman Tentang & Rekam Jejak**: Cerita profil, foto profil asli terverifikasi, matriks keahlian dengan tautan proyek pembuktian, linimasa kepemimpinan/organisasi, dan sertifikasi kompetisi robotika.
- **Formulir Kontak Tervalidasi**: Validasi input sisi klien & server (`/api/contact`), proteksi honeypot anti-spam, serta saluran komunikasi langsung (Email, GitHub, LinkedIn).
- **Curriculum Vitae Siap Cetak/PDF**: Tampilan CV dwibahasa yang rapi dan terformat untuk print-to-PDF tanpa nomor telepon (menjaga privasi).
- **SEO & Performa**: Generator sitemap (`/sitemap.xml`), `robots.txt`, dan metadata Open Graph.

---

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/) + Custom Hardware/Brand SVGs
- **Deployment Ready**: Vercel / Cloudflare Pages / Node.js Server

---

## Cara Menjalankan

### 1. Instalasi Dependensi
```bash
npm install
```

### 2. Menjalankan Server Pengembangan
```bash
npm run dev
```
Buka [http://localhost:3000](http://localhost:3000) pada browser Anda.

### 3. Kompilasi & Build Produksi
```bash
npm run build
npm run start
```
